## Acquisition and integrity

- GFS: NOAA READY server-side regional extraction of four daily ARL archives,
  23–26 September 2019. Requested domain 75–130° E, 20° S–20° N; 221 × 161
  native grid points, 55 atmospheric levels plus the surface. Each uncompressed
  file has eight three-hourly times and 349 records per time. ZIP CRC, local
  SHA-256, record counts, variables and times are checked. Extraction selections,
  job identifiers and provider result pages are preserved beside the data.
  Local SHA-256 is an integrity fingerprint, not an independently published
  provider checksum for the regional crop. Whole-global downloads were replaced
  by this bounded extraction; interrupted global bytes remain resumable.
- EDGAR: public v8.0 monthly sector archives, eight sectors each for CO₂ and CH₄.
  HTTP byte-range extraction selects only the 2019 NetCDF member from each ZIP.
  ETag matching and ZIP CRC validate the extracted member. Range blocks are
  cached for restartability; raw annual files retain all twelve months, while
  analysis reads only September and the required regional coordinates.
- GFED: public GFED5.1 daily data. SSH host keys are pinned on first access,
  then verified strictly. Published access credentials are fetched into memory
  only and never persisted or printed. HDF5 reads select four relevant days,
  three gases and the regional grid. The source stores daily labels at 01:00;
  the scientific scenario assigns each labelled day its uniform 24-hour UTC
  flux. Native labels, source units, source-file size and subset SHA-256 are
  retained. Interrupted full-file transfers are not analytical inputs.
- Indonesia: the unchanged shared `indonesia_38prov.geojson` asset. Invalid
  geometries are repaired in memory. Foreign boundaries: full-resolution
  geoBoundaries gbOpen polygons and country-specific metadata, not Natural Earth
  substitutes for Indonesia. Source URLs, licenses, vintages and hashes remain
  in the acquisition and cartographic provenance records.

Provincial geometry contains overlapping claims. Quantitative allocation
subtracts the union of pairwise overlaps from each claimant and records that
area as unassigned, rather than choosing a province or proportionally dividing
a disputed area. Map geometry and the shared asset are not changed. Tests cover
both two- and three-way overlap.

## Scientific implementation details

`a39_bkt_refinement.read_run` applies requested/emitted-count normalization to
native HYSPLIT output. The principal 10,000-particle request emits 10,020
particles. That normalization is uniform within each run and does not change
its relative spatial shares. Earlier controlled normalization experiments remain
in the refinement output directory, outside the reader-facing report.

The STILT mixed layer uses modified Richardson-number diagnosis (`KMIXD=3`),
not the archived native `PBLH` field. The latter is plotted solely as
meteorological context. GFS lacks Grell convective-flux inputs; requesting the
optional scheme is not evidence of active Grell redistribution. The model uses
default non-WRF vertical interpolation for these global meteorological inputs.

EDGAR kg m⁻² s⁻¹ is multiplied by 10⁹/M, with M in g mol⁻¹. GFED g cell⁻¹ day⁻¹
is divided by spherical cell area and 86,400 s and multiplied by 10⁶/M. The
resulting µmol m⁻² s⁻¹ flux is conservatively area-averaged onto the footprint
grid. Multiplication by discrete coefficients gives ppm; CH₄/CO presentation
uses 1,000 ppb per ppm. No second area or timestep factor is applied.

Both source-convolution NetCDF files store every gas's `enhancement` in the
same unit, ppm (`units = 1e-6`). Tables and figures explicitly multiply CH₄
and CO by 1,000 for ppb; a single data variable never mixes ppm and ppb values.

The fixed-GFS three-seed range excludes flux and structural uncertainties.
EDGAR and GFED totals remain separate because agricultural burning can overlap
and source-height assumptions are unresolved. No biospheric or background
concentrations are manufactured to close the measured gas budget.

The output grid is a bounded regional source domain, smaller than the
meteorological domain. GFS has nonzero eastern edge sensitivity. The analysis
records it explicitly rather than asserting complete capture; the edge share
does not bound unrecorded influence farther east. A wider-domain experiment
is required for a complete-capture claim. This limitation does not change the
definition of the reported within-domain flux convolution.

## Output contracts and validation

All new model and source evidence is under `outputs/hysplit/gfs/analysis`:
ensemble NetCDF fields, EDGAR/GFED matched flux and contribution fields,
source/transport/meteorological tables, PNG/PDF figures, report expansion values,
boundary metadata and validation output. Source data remain under `data/`.

Checks must cover raw-run timestamps and counts, meteorological integrity,
nonnegative/finite coefficients and fluxes, complete sector coverage, remapping
and convolution equivalence, provincial overlap, display conservation, exact
report expansion, no internal-development narrative, and final PDF rendering.
The full repository gates remain required. A successful process alone is not
completion; see the current execution plan for unfinished work.

PDF regression checks include the Results heading's association with its first
subsection and substantive findings. BKT-specific figure placement and barriers
prevent pending figures from interfering with following tables; other report
layouts keep their previous settings.
